Description:
Developed an AI-powered Coconut Tree Disease Detection System that identifies diseases from coconut leaf images using Deep Learning and Computer Vision. The system provides disease diagnosis, causes, symptoms, treatment recommendations, multilingual support, voice-assisted explanations, and Telegram Bot integration for remote farmer assistance.

Technologies Used:
Python
Flask
TensorFlow / Keras
OpenCV
NumPy
HTML, CSS, JavaScript
SQLite/MySQL
Google Translate API
Text-to-Speech (TTS)
Telegram Bot API



Key Highlights:
Deep Learning-based image classification
Real-time disease prediction
Voice Assistant integration
Multi-language support
Telegram Bot automation
Agricultural product recommendations
